# EVM Dashboard

Aplicación fullstack para gestionar proyectos y actividades y calcular automáticamente los indicadores de Valor Ganado (Earned Value Management).

Prueba técnica de Ingeniero de Desarrollo — Trycore Colombia.

> Este README se completará al final con las instrucciones para correr el proyecto y el script de inicialización de la base de datos.

## Stack

- Backend: Python + FastAPI + SQLAlchemy + Pydantic
- Base de datos: PostgreSQL 17
- Frontend: React + Vite (JavaScript) + Recharts
- Calidad: pytest, pytest-cov, ruff, ESLint
